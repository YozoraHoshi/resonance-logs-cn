# Changelog v0.2.2

## 更新内容

### DPS / 履歴

- Live 計時をフロントエンドの自然時計に変更し、戦闘パケット間隔による時間ジャンプを回避
- ダミー訓練モードで訓練時間を設定可能に（DPSメーター → 設定 → 訓練用ダミー）
- ダミー訓練の状態表示を修正
- ダミーボタンのスタイルを独立設定できない問題を修正
- 履歴をクリアした後に通し番号がリセットされない問題を修正
- 死亡リプレイで最後の一撃が記録されない場合がある問題を修正
- マップ切り替え / 区間分割後に DPS の幻想表示と死亡リプレイがクリアされる問題を修正
- 同時刻にスキルを確認すると重複 key で固まる問題を修正
- ボスの誤認識を修正
- 召喚物が幻想として扱われ、DPS 画面に表示されない問題を修正
- 履歴のホバーヒントをタイトルバーへ移し、重なりを回避
- 履歴プレイヤー表に戦闘全体の最近の幻想2種を表示可能（階数付き。旧記録は階数なし）
- 履歴タイムライン曲線の高さをカスタム可能（DPSメーター → 設定 → 履歴、または画像上で直接調整）
- 履歴で味方の DPS 曲線を任意表示可能に
- 履歴に DPS 画面と同じ幻想表示を追加（DPSメーター → 設定 → 履歴）

### オーバーレイ監視

- overlay ウィンドウを統合
- 味方 Buff の描画ロジックを最適化
- ダンジョンギミックで自身が対象のとき、名前を矩形で強調

### モジュール

- モジュール計算でモジュールデータを取得できない問題を修正

### 安定性

- フロント / バックエンドのデータパイプラインを再構築し、Web のピークメモリ使用量を抑制
- フロント / バックエンドの起動順序により Live ウィンドウが登録できずデータが表示されない問題を修正

## 注意事項

### 互換性

- 0.0.2 または 0.0.3 を使用していた場合、0.0.4〜0.2.2 を初めて使う際は `%LOCALAPPDATA%\resonance-logs-cn` 配下の `resonance-logs-cn.db` を削除してからアプリを再起動してください
- 0.2.2 と 0.2.1 は大規模な再構築を行っています。既存機能に問題があれば速やかにご連絡ください
- 0.2.2 はテーブルフィールドを変更しています。古い履歴レコードのエラーは想定どおりで、新しい記録は正常です
- 音声読み上げはモデルを別途ダウンロードする必要があります。初回のフレーズ生成には時間がかかることがありますが、生成後の再生ではモデルを再読み込みしません

### 特に注意

- コードを改変して PR せずに配布する場合は、アプリ名・バージョンなど本家の識別情報を必ず変更し、誤解を招かないようにしてください
- 閉じるボタンは右下に隠れます。ウィンドウが多い場合は隠れバーを右下へドラッグして表示できます
- よくある質問は利用マニュアルの HTML を参照してください
