# Changelog v0.2.3

## 更新内容

### DPS / 履歴

- ダミー訓練モードにロック方針「最初のモンスター命中」を追加（DPSメーター → 設定 → ライブ → 訓練ロック）
    - 既定は協会ダミーで、最初の命中後にロックする
- DPS と履歴の時間は、最後の一撃による区間分割で計算するように変更
    - 真の秒間ダメージは引き続きアクティブ戦闘時間で計算
- DPS テーブルの列名をカスタム可能に（DPSメーター → 設定 → ライブ / 履歴 → 一般設定）
- 履歴の味方曲線を再度クリックすると瞬間 DPS 曲線に切り替え可能
- 履歴曲線の表示を改善
- バフ稼働率を追加：ライブモニターで監視リストを設定し、リアルタイム overlay では自身の稼働率を表示、履歴ではパーティ全体の稼働率を集計
    - ライブモニター → バフ稼働率で設定。自身が気にする Buff は「リアルタイム表示」をオン、味方が気にする Buff はオフ（履歴に反映）

  ![リアルタイム Overlay の Buff 稼働率](../../shared/img/changelog/v0.2.3_1.png)

  ![履歴の Buff 稼働タイムライン](../../shared/img/changelog/v0.2.3_2.png)

  ![履歴の Buff 稼働率集計](../../shared/img/changelog/v0.2.3_3.png)

- DPS / 履歴の死亡リプレイレイアウトを改善し、死亡 Buff スナップショットを折りたたんで後ろへ移動
- 死亡リプレイの被弾に物理/魔法と属性を表示でき、列の表示/並び替えに対応（既定は時間、スキル、ソース、ダメージ）（DPSメーター → 設定 → ライブ / 履歴 → 死亡リプレイ列）
- 履歴の死亡リプレイ表頭揃えを DPS/回復と同じにした（テキスト列は左、その他は右）
- 履歴レコードのスタイルを調整
- フォートレスが道中で自動リセットされない問題を修正
- 鏡の中の審判の第1段階が異常リセットされる問題を修正

### オーバーレイ監視

- 荒蕪の庭のダンジョンギミックを追加

  ![荒蕪の庭・虚痕マッチ](../../shared/img/changelog/v0.2.3_4.png)

  ![荒蕪の庭・エネルギー球追跡](../../shared/img/changelog/v0.2.3_5.png)

- モンスターモニターとライブモニターのスタイルを統一
- エンティティ消失時に攻撃対象をクリアしなくなり、モンスターモニターが以降も更新を受け取れるように修正
- バフ稼働率付近のキャラクター表示が欠ける問題を修正
- シーズンノードエリアとバフ稼働率エリアでアイコンなし Buff が重複表示される場合がある問題を修正
- 重装セットカウンターを追加（ライブモニター → カスタムモニター → カウンターを追加）
    - 重装S4・自動竜砲
    - 重装S4・追加神影螺旋
- フロストメイジセットカウンターを追加（ライブモニター → カスタムモニター → カウンターを追加）
    - 射线S4・氷の灌注4セット

### 音声

- 「マッチ成立」「準備確認」「ダンジョン投票」の音声通知を追加し、内蔵プリセット音声を提供（音声読み上げ → マッチ通知）

### アプリ設定

- 「閉じるボタンでアプリを終了する」設定を追加（アプリ設定 → 一般 → アプリの動作）
- 一部の英語・日本語翻訳を改善

### 安定性

- DPS と Overlay ウィンドウの切り替えで互いのデータが消える問題を修正し、ウィンドウ切り替え制御を簡素化

## 注意事項

### 互換性

- 0.0.2 または 0.0.3 を使用していた場合、0.0.4〜0.2.3 を初めて使う際は `%LOCALAPPDATA%\resonance-logs-cn` 配下の `resonance-logs-cn.db` を削除してからアプリを再起動してください
- 0.2.2 と 0.2.1 は大規模な再構築を行っています。既存機能に問題があれば速やかにご連絡ください
- 0.2.2 はテーブルフィールドを変更しています。古い履歴レコードのエラーは想定どおりで、新しい記録は正常です
- 音声読み上げはモデルを別途ダウンロードする必要があります。初回のフレーズ生成には時間がかかることがありますが、生成後の再生ではモデルを再読み込みしません

### 特に注意

- コードを改変して PR せずに配布する場合は、アプリ名・バージョンなど本家の識別情報を必ず変更し、誤解を招かないようにしてください
- 閉じるボタンは右下に隠れます。ウィンドウが多い場合は隠れバーを右下へドラッグして表示できます
- よくある質問は利用マニュアルの HTML を参照してください
